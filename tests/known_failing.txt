#   - переименования, меняющие смысл запроса молча: duration_seconds → duration,
#     chat_filter → chat_id, search → q, init_db → init_db_with_fallback,
#     delete_message → delete_ephemeral_message (v4.7.20, BUG#2);
#   - сменившийся контракт роута: /api/unban отвечает 303-редиректом с flash,
#     а не JSON, и определяет цель по user_id+chat_id, а не по punishment_id;
#   - гейты, добавленные позже тестов (v4.7.2: sanitary_days_enabled);
#   - MagicMock вместо AsyncMock для message.bot: методы Bot API асинхронные;
#   - грепы по исходнику, ищущие код там, откуда его вынесли: ветки команд —
#     в mod_commands.py, _alarm_auto_off_tick — в chat_modes.py;
#   - зашитые в ассерты номера версий, подписи UI и точные формулировки;
