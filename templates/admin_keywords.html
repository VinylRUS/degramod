Keyword watch list #

Список фраз, которые бот отслеживает в сообщениях всех чатов. При упоминании фразы бот шлёт оперативное оповещение в modchat (не в report_chat!). Modchat должен быть назначен на странице /admin/chats (кнопка ☆ MOD в карточке чата).

День (не активен night mode): только notify в modchat — бот не банит, не удаляет, не варнит. Дежурный модератор сам решает, что делать.
Ночь (active night mode): фразы с флагом ban_in_night_mode → автобан. Фразы без флага → только notify.

Match logic (минимум ложных срабатываний):

  • Case-insensitive (без учёта регистра).
  • Фраза с пробелом → substring match (ищет последовательность целиком). Пример: «срал в торт детишкам» найдёт только эту фразу, не отдельные слова.
  • Одиночное слово → word-boundary match (не сработает на «замодераторили» если в списке «модератор»). Это убирает ~90% ложных срабатываний без regex.

Антиспам modchat'а: rate-limit 60 сек/фраза (повторы в течение минуты схлопываются в одно уведомление со счётчиком) + multiplexing (3 совпадения в одном сообщении → 1 notify со списком фраз) + exempt модераторов/админов/SU (через _is_admin).

💡 Эквивалентные TG-команды (бэкап): !addkeyword "фраза" [--ban-night], !delkeyword "фраза", !listkeywords. Все команды — SU-only. Этот список синхронизирован с командами (та же таблица keyword_watch).

Подсказки:
  • Если на странице /admin/chats не назначен modchat — уведомления о срабатываниях keyword-watch пропадают (молча игнорируются). Назначьте modchat кнопкой ☆ MOD.
  • Modchat и report_chat — взаимоисключающие роли. Если чат уже report_chat — кнопка MOD недоступна, и наоборот.
  • Match logic НЕ распространяется на сообщения от модераторов/админов/SU (exempt через _is_admin). Это чтобы модератор мог спокойно обсуждать фразы из списка в рабочем контексте.
  • Редактирования сообщений не триггерят keyword-watch (только новые сообщения).
  • Media-only (без текста/caption) игнорируются. Бот матчит message.text + message.caption.
