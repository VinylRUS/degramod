Safety #
What is preserved:
  • moderators — Telegram moderators (created on first bot command in a chat)
  • web_users — SU + all web-panel admins (created via /admin/users)
  • chat_settings — per-chat config: hashtag, warn thresholds, report-chat override
What is deleted:
  • punishments — all warn/mute/ban/unmute/unban/unwarn records (test violations)
  • users — all entries except those whose user_id matches a mod_id in moderators
  • chat_admins — only if the checkbox is checked
Operational notes:
  • The bot keeps running during cleanup (SQLite WAL mode allows concurrent access)
  • Foreign keys are ON — deletions happen in the right order (punishments first, then users)
  • VACUUM runs after deletion to compact the DB file
  • The backup file is created in the same directory as the DB — make sure that volume is persistent
  • This page is SU-only — regular admins cannot see or trigger cleanup
