Presets & Filters #
Что здесь настраивается:
• Permission presets — именованные наборы из 13 прав ChatPermissions для day/night/sanitary режимов. Привязываются к чату на странице /admin/chats.
• Ban words (word filter) — список запрещённых слов/regex-паттернов. chat_id=0 — глобальные (для всех чатов); per-chat — только для конкретного чата. Применяется только если word filter включён в чате (через команду /addword или здесь).
• Link allowlist — домены, разрешённые link-filter-ом. Все остальные домены блокируются. chat_id=0 — глобальный allowlist.
Паритет с командами: изменения в UI эквивалентны командам /addword, /delword, /linkallow (и видны через /listwords, /linkallowlist).
Как это работает:
Пресет — это именованный набор из 13 прав ChatPermissions (text, audios, docs, photos, videos, vnotes, voices, polls, stickers/GIFs, link previews, change_info, invite_users, pin_messages).
Один пресет можно привязать к нескольким чатам, но в каждом чате сохраняется копия JSON — изменение или удаление пресета не ломает уже настроенные чаты.
Scope: day — дефолтные права чата; night — права на время ночного режима; sanitary — права на время санитарного дня.
Системные пресеты (Full lockdown, Text only, Day default) — неудаляемы, создаются автоматически при первом запуске.

🚫 Ban Words (Word Filter) #
Список запрещённых слов/паттернов. Применяется ко всем сообщениям с текстом — если в тексте найдено совпадение (substring или regex), применяется действие (delete / warn / mute / ban).
Scope: chat_id=0 (Global) — применяется ко всем чатам; per-chat — только к указанному чату. Per-chat имеет приоритет над global (если совпадают оба — сработает per-chat).
is_regex=on — pattern компилируется как Python regex через re.search. Иначе — case-insensitive substring.
Паритет с командами: /addword chat_id <pattern> [action] [is_regex], /delword chat_id <pattern>, /listwords [chat_id].

🔗 Link Allowlist #
Список доменов, разрешённых link-filter-ом. Если link-filter включён для чата (через toggle на /admin/chats или /linkfilter chat_id on), все ссылки на домены не из этого списка будут блокироваться действием link_filter_action (настраивается в чате).
Scope: chat_id=0 (Global) — разрешён для всех чатов; per-chat — дополнение к глобальному списку.
Сравнение по подстроке: t.me разрешит t.me, telegram.t.me и любые поддомены.
Паритет с командами: /linkallow chat_id|global <domain>, /linkallowlist [chat_id].
