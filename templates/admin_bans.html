Active bans #

Список всех активных банов по всем чатам (где есть записи в БД). Баны берутся из таблицы punishments с action_type='ban' и is_revoked=False. Записи с mod_id=0 — системные (CAS auto-ban, content-filter, keyword-watch night auto-ban).

Кнопка Unban в каждой строке: soft-revoke исходной записи (помечает is_revoked=True), дёргает Telegram API unban_chat_member(only_if_banned=True) и создаёт новую запись action_type='unban' с указанием модератора и причины (опциональной). Это полный паритет с TG-командой !unban (вызов переиспользуемой функции revoke_user_ban).

Доступ: все активные веб-юзеры (admin + SU + moderator).
Лимит: 200 строк на страницу (свежие сверху — сортировка по created_at DESC).

Подсказки:
  • Сортировка — свежие сверху (по created_at DESC).
  • Записи с mod_id=0 — системные (CAS auto-ban, content-filter, keyword-watch night auto-ban, via-bot filter). Их тоже можно разбанить.
  • Unban через веб-API не отправляет отчёт в репорт-чат (это специфика TG-команды !unban). Все остальные шаги (soft-revoke + Telegram unban + новая запись action_type='unban') — идентичны.
  • Если у пользователя нет аватарки или профиля в БД — это нормально. Профиль создаётся при первом взаимодействии с ботом. Unban сработает даже без профиля.
  • Для batch-операций (массовый разбан) — используйте SSH-скрипт scripts/cleanup_test_data.py или прямой SQL. Веб-UI не поддерживает batch.
