Help #
Hashtag — short label for the chat, shown in reports next to the chat ID (e.g. #Деградач, #Бэбэй). Optional. Auto-prefixed with # if missing. Report chat ID — Telegram chat ID where violation reports are sent. Three modes:
  • empty — use the default report chat (the chat_id=0 row's report_chat_id, falling back to env REPORT_CHAT_ID)
  • 0 — disable reports for this chat entirely
  • specific ID — override per-chat (e.g. send this chat's reports to a private moderation group)
Warns → mute — number of warns that auto-triggers a mute. 0 disables auto-mute. When a user reaches this many active warns in this chat, the bot mutes them for Mute duration seconds. Warns → ban — number of warns that auto-triggers a ban. 0 disables auto-ban. Same logic as mute, but with a ban (no duration). Default row (chat_id=0) — applies to all chats that don't have their own override. Editable here like any other row. Access — visible to SU and admin. Moderator role cannot see this page (redirect to /dashboard).
