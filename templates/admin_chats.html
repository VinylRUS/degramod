All chats #
Chats are detected automatically when the bot is added to them. For each chat you can: set a hashtag (for reports), assign a report chat (where moderation logs go), configure warn thresholds, mark a chat as private (admins won't have access, only SU and explicitly-assigned moderators), disable the bot in a chat (it will completely ignore everything in the chat — no commands, no logging, no auto-detection; as if the bot isn't there), delete a chat (the bot leaves the chat and all related data — settings, moderators, punishment history — is removed; use for test chats), or mark one chat as the global report chat. Chat title is fetched from Telegram; if missing, the bot was probably added without admin rights.

v4.5.1: multiple chats can be marked as report targets (☆ button on each). Then for each regular chat you pick which report chat to use (dropdown in Settings). Setting warns_to_mute=0 disables auto-mute entirely; warns_to_ban=0 disables auto-ban.
