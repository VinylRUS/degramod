User management #
v4.7.0: ручное создание пользователей упразднено. Учётки теперь создаются автоматически через Sync admins from TG — кнопку в карточке чата на странице /admin/chats.
Как это работает:
1. SU открывает карточку чата → «Sync admins from TG».
2. Бот получает список TG-админов и создаёт для каждого pending-учётку (is_active=False, без пароля).
3. Юзер, который стал админом чата, пишет боту /start в ЛС → бот генерирует пароль, активирует учётку и шлёт DM с логином/паролем.
4. Если у юзера есть can_promote_members (=owner) → роль admin, иначе moderator (привязан к своему чату).
5. Если TG-owner снимает админа — при следующем sync его WebUser деактивируется.
Ниже в таблице — список всех WebUser (активные, pending и деактивированные). SU может: деактивировать, сменить роль, сбросить пароль, удалить, привязать другой TG ID.
