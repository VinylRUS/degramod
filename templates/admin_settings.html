Database maintenance #
Three operations on the SQLite database file: Backup creates a timestamped copy, Cleanup wipes test data, VACUUM reclaims free space. All safe to run on a live bot (WAL mode).
{# ── Backup ───────────────────────────────────────────────────────────────── #}
Backup #
Creates a timestamped copy of the SQLite DB file in the same directory. Useful before risky operations or as a regular snapshot. The bot keeps running during backup (WAL mode allows concurrent access).
{{ csrf_field() }}
{# ── Cleanup ──────────────────────────────────────────────────────────────── #}
Cleanup #
Live preview from the current database. Deletes all test punishments and non-moderator users. Preserves moderators, web users, chat settings. A backup is created automatically before deletion.

moderators {{ counts.moderators }} PRESERVED 0
web_users {{ counts.web_users }} PRESERVED 0
chat_settings {{ counts.chat_settings }} PRESERVED 0
{% if counts.moderators == 0 and counts.web_users == 0 %}
Refusing to apply: the database has no moderators and no web users. This usually means you're running cleanup on a wrong/fresh database. Create at least one admin or moderator before running cleanup.
{% endif %}

{# ── VACUUM ───────────────────────────────────────────────────────────────── #}
VACUUM #
Rebuilds the database file, reclaiming free space left after deletions. Does not delete any data — safe to run anytime. The bot keeps running during VACUUM (WAL mode).

GitHub Projects #
Интеграция с GitHub для команды !idea. Модераторы и админы пишут !idea <текст> в ЛС боту или в modchat — идея создаётся как GitHub Issue в указанном репозитории и автоматически добавляется в GitHub Project v2 (колонка «Предложено»). Метаданные (автор, дата, источник) сохраняются в БД бота, Issue остаётся чистым. PAT шифруется через Fernet (ключ в {{ db_path_dir }}/.github_enc_key).
