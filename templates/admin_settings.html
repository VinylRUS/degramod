{# ── v4.8.5: GitHub Projects ───────────────────────────────────── #}
GitHub Projects #
Интеграция с GitHub для команды !idea. Модераторы и админы пишут !idea <текст> в ЛС боту или в modchat — идея создаётся как GitHub Issue в указанном репозитории и автоматически добавляется в GitHub Project v2 (колонка «Предложено»). Метаданные (автор, дата, источник) сохраняются в БД бота, Issue остаётся чистым. PAT шифруется через Fernet (ключ в {{ db_path_dir }}/.github_enc_key).
